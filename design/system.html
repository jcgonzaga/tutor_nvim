Tutor NeoVim — sistema visual

Grafito y ámbar. El fondo se calla para que el código sea lo único que brille, y el cursor ámbar guía la mirada en cada pantalla. Todos los valores de esta lámina salen de apps/web/src/index.css.

Los tokens de abajo son los únicos del proyecto. No hay escalas de espaciado, radios ni sombras tokenizadas: los artboards usan valores puntuales.

Foco, código y estados

Anillo de foco único: 2 px ámbar con 2 px de separación, en todo elemento enfocable.

const mode = "development";
const target = "production";

El cursor es un bloque ámbar con tinta oscura encima: se lee aun sobre el código.

Óptima Válida No aceptada Bloqueada
